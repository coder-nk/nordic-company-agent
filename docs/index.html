Key Features

  • ✅ Legal Identity: Name, form, status, addresses, industry codes, employees, capital
  • ✅ Financials: Latest 3 filed accounts (revenue, profit, assets, equity, ratios)
  • ✅ Leadership: Board members, CEO, auditors, accountants with role dates
  • ✅ Workplaces: Registered locations with addresses and employee counts
  • ✅ Website Verification: L1 (org number on page) and L2 (registry-filed + corroboration)
  • ✅ Social Profiles: Linked from verified website or Wikidata P2333 match
  • ✅ Job Postings: Active NAV ads by employer org number
  • ✅ Public Activity: State aid grants, R&D tax credits, registry events
  • ✅ Interactive UI: Search, compare, evidence drawers, live research mode
